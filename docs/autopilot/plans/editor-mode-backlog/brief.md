## 三、重要：S1 有一处结论已失效

`gap-todo.md` 写于 `423aed2` **之前**，其「一句话结论」称：

> 「现在是纯模型对话，AI 不能改代码……核心交互闭环缺最后一环『看』」

改造后侧栏 Chat **就是 DSH 真实 Agent 会话**（能读文件、跑命令、改代码），
因此：

- ❌ 「AI 不能改代码」不再成立
- ❌ 「MCP 接入会打破纯对话边界」的论述不再成立（DSH 已有 MCP 资源服务）
- ✅ 「**AI 改动不可见**（缺 diff 审核）」这条**依然成立且更关键**——
  现在 Agent 真的会改文件，用户更需要一个审阅入口

整理后的清单已按此修正，并把 `gap-todo.md` 本身列为「待更新文档」。
同理，S1 中「模型接入 / 上下文注入」相关的行需按会话模型重述。
